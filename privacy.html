Kebijakan Privasi rclone-mimi

Berlaku sejak 8 November 2026.

Data yang diakses

rclone-mimi meminta akses Google Drive hanya untuk akun Google milik pemiliknya sendiri, Rahmat Riyadi. Akses dipakai untuk membaca, menyalin, dan mengunggah file di folder kerja pemilik.

Penyimpanan dan berbagi

Token akses disimpan hanya di server pribadi pemilik. Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan.

Pengguna lain

Aplikasi ini tidak ditujukan untuk orang lain. Tidak ada data pengguna lain yang dikumpulkan.

Mencabut akses

Akses dapat dicabut kapan saja lewat Pengaturan akun Google.
