rclone-mimi

rclone-mimi adalah konfigurasi pribadi alat sumber terbuka rclone milik Rahmat Riyadi. Alat ini berjalan di server rumah pribadi untuk menyalin dan membaca file di Google Drive milik pemiliknya sendiri (folder kerja les dan kuliah).

Aplikasi ini tidak melayani pengguna umum dan tidak dijual. Hanya pemilik yang memakainya.
